# homebrew-saetta

    brew install antonellof/saetta/saetta    # one line

or, for the short name (Homebrew asks you to trust a third-party tap first):

    brew tap antonellof/saetta && brew trust antonellof/saetta    # once
    brew install saetta                                           # later: brew upgrade saetta

Installs [saetta](https://github.com/antonellof/saetta) 0.9.0, the release binary for Apple Silicon.
